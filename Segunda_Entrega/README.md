# Segunda entrega: DFO-GN simplificado

Proyecto Integrador de Métodos Numéricos (Externado, 2026-2). David Castro, Alejandro Pardo, Tomás Rincón.

## Ejecutar

Descarga un cuaderno de `cuadernos/` y ábrelo en Colab o Jupyter. Luego ejecuta todas las celdas. Cada cuaderno funciona solo, sin otros archivos.

| Cuaderno | Contenido |
|---|---|
| `01_metodos_y_validacion.ipynb` | Gauss con pivoteo, QR, problemas de prueba y validación |
| `02_dfogn_y_comparadores.ipynb` | DFO-GN explicado por partes y métodos de comparación |
| `03_experimentos.ipynb` | Todas las tablas y figuras del informe (unos minutos) |

Semilla: `SEMILLA = 2026`. Versiones usadas: `requirements.txt`. En otra versión de las bibliotecas podrían cambiar los últimos decimales. Los tiempos cambian en cada ejecución.

## Otros archivos

| Archivo | Contenido |
|---|---|
| `informe/` | Informe en PDF y su fuente en Markdown |
| `EXPLICACION_METODOS.md` | Explicación de cada método y su relación con la asignatura y el artículo |
| `resultados/`, `figuras/` | Salidas de `03_experimentos.ipynb` |
